# Privacy Policy — HsData Attendance System Backup Tool

This application is an internal tool used by school staff to back up the
local attendance database (HsData.db) to the user's own Google Drive.

## What data this app accesses
This app uses Google's `drive.file` scope, which means it can only access
files that it creates itself. It cannot view, modify, or delete any other
files already in your Google Drive.

## What data is uploaded
Only the local SQLite attendance database file is uploaded, as a timestamped
backup copy, to the Google Drive account of the person who authorizes the app.

## Data sharing
No data collected or uploaded by this app is shared with any third party.
All backup files remain solely within the authorized user's own Google Drive
account.
